Navigate a tab: goto a URL, reload, back, or forward. Waits for the load event.


## Parameters

<ParamField body="tabId" type="integer">
  Target tab id from browser_tabs, which lists tabs across all windows. Defaults to the agent's most recently opened usable tab, or the only usable tab. Otherwise select a listed tabId.
</ParamField>

<ParamField body="action" type="enum" required default="goto">
  One of: `goto`, `reload`, `back`, `forward`.
</ParamField>

<ParamField body="url" type="string">
  Required for goto
</ParamField>

<ParamField body="timeoutMs" type="integer">
  &nbsp;
</ParamField>

## Example

```json 
{
  "tabId": 1234,
  "url": "https://example.com/login"
}
```
