Fetch a URL and return its main content as markdown (or text/html): opens a background agent tab, waits for load, reads, closes. Choose browserId for an extension browser or context for a developer browser when several are connected. Use for reading docs and articles.

<Note>The tool names stay the same across browsers. See [browser selection](/reference/multiple-browsers) and [Firefox and Zen exceptions](/reference/firefox) before choosing an operation.</Note>

## Example

```json Read main content

}
```

```json Read using a specific browser
{
  "url": "https://example.com",
  "browserId": "ext:example-browser-id"
}
```

Use a connected browserId from browser_status.
