Instant 360-degree page health check: evaluates console runtime errors, failed network requests, horizontal layout overflow (scrollbars), broken images, WCAG 2.1 AA accessibility (unlabelled buttons/inputs, duplicate IDs), Core Web Vitals, and SEO. Works in both Extension and Developer modes without external dependencies. Returns a health score (0-100), letter grade, and actionable element refs [ref=e12].

<Note>The tool names stay the same across browsers. See [browser selection](/reference/multiple-browsers) and [Firefox and Zen exceptions](/reference/firefox) before choosing an operation.</Note>

<Note>Runs in-page checks for layout overflow, broken images, WCAG accessibility, and SEO, and scans active DevTools capture sessions for runtime console errors and failed network requests. Works in both Extension and Developer modes across Chromium and Firefox.</Note>

## Parameters

<ParamField body="tabId" type="integer">
  Target tab id from browser_tabs, which lists tabs across all windows. Defaults to the agent's most recently opened usable tab, or the only usable tab. Otherwise select a listed tabId.
</ParamField>

<ParamField body="categories" type="enum[]">
  Categories to audit (default: all) Items: `errors`, `network`, `layout`, `accessibility`, `performance`, `security`, `seo`.
</ParamField>

<ParamField body="threshold" type="enum" required default="all">
  Filter findings: "all", "warnings", or "errors" only One of: `all`, `warnings`, `errors`.
</ParamField>

<ParamField body="summaryOnly" type="boolean">
  Return scores and counts without individual item details
</ParamField>

<ParamField body="saveReport" type="boolean" required default="true">
  Save diagnostic report artifact (default: true)
</ParamField>

## Example

```json Full 360-degree health audit of the active page
{
  "tabId": 1234
}
```

```json Check responsive layout and accessibility only
{
  "tabId": 1234,
  "categories": [
    "layout",
    "accessibility"
  ]
}
```

```json Errors only
{
  "tabId": 1234,
  "threshold": "errors"
}
```
