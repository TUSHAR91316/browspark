Application storage. area: cookies (list/set/delete), local or session storage (list/set/remove/clear), indexeddb (databases/stores/data/put/clearStore/deleteDatabase), cache (list/entries/delete), usage (quota and per-type usage), clear (explicitly named storage types for one origin). Origin defaults to the page origin.

## Example

```json Cookies for the page origin
{
  "tabId": 1234,
  "area": "cookies",
  "action": "list"
}
```

```json Set a localStorage key
{
  "tabId": 1234,
  "area": "local",
  "action": "set",
  "key": "featureFlag",
  "value": "on"
}
```

```json Read an IndexedDB store
{
  "tabId": 1234,
  "area": "indexeddb",
  "action": "data",
  "database": "app",
  "store": "todos",
  "pageSize": 20
}
```

```json Clear named storage types for the origin
{
  "tabId": 1234,
  "area": "clear",
  "types": [
    "cookies",
    "local_storage"
  ]
}
```
