Click the extension icon to open the dashboard in a full browser tab. The sidebar has Overview, Graph, Tabs, Tools, Activity and Settings. Graph is enabled by default and can be hidden in Settings. The sidebar also shows the connection state, a theme switch (system, light, dark) and the extension and companion versions.

Each browser profile with the extension has its own dashboard, showing that profile's tabs, connection and settings. Open [Graph](/dashboard/graph) to see the agents, browser profiles and developer sessions connected to the same companion. Ask the agent for `browser_status` to get their browser and tab IDs; separate developer sessions have no extension dashboard.

In Firefox or Zen, the dashboard shows **Allow website access** if the all-websites permission is missing, followed by **Enable Firefox automation** to grant user-script permission. Website access also enables Firefox's native tab screenshots; Browspark only automates shared HTTP/HTTPS tabs. Share the tabs you want to use after granting these permissions. See [Firefox extension setup](/reference/firefox#install-the-firefox-extension).

## Connection card

Shows whether this profile's extension is connected to the companion (`127.0.0.1:<port>`), reconnecting, or stopped, how long the session has been live, and the companion version. **Stop** and **Resume** affect this profile, as on the Settings page.

## Setup

A client picker (Claude, Codex, OpenCode, Cursor, Kilo, Antigravity) with the exact command or JSON to paste, a copy button, the file it belongs in, what to do next, and a link to that client's MCP documentation. The snippets already include `--port` when you changed the bridge port. Full text of each is in [Connect an agent](/connect/agents).

## Numbers

Shared tabs and attached tabs are always shown. **Operations** and **Errors** count commands since the extension started and appear only while the [activity log](/dashboard/activity) is on; with it off nothing is counted.

## Stale worker banner

When you rebuild the extension without reloading it, the files on disk are newer than the running service worker. The dashboard detects a version mismatch and shows a banner asking you to reload the extension. Reload it in every connected profile, using `chrome://extensions` in Chrome, `brave://extensions` in Brave, or `about:debugging` in Firefox and Zen. The same banner appears when the running worker predates a setting the dashboard expects.
